# MedClarity

### AI-Powered Medical Report Simplifier

MedClarity converts complex medical reports into simple, easy-to-understand language. It helps users understand test results, findings, abnormal values, and medical terminology through a clean and user-friendly interface.

## ✨ Features

- 📄 Medical report upload & text extraction
- 🧠 AI-powered medical terminology simplification
- 📊 Clear test result visualization
- ⚠️ Abnormal finding identification
- 📋 Simple report summaries
- 🌐 Multi-language support
- 🔊 Audio report playback
- 🫀 Interactive organ/body visualization
- 🩺 Doctor consultation preparation
- 📱 Responsive UI
- 💾 Report history

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, Tailwind CSS  
**Backend:** Python, FastAPI, SQLAlchemy, SQLite  
**Processing:** PDF/OCR, Medical Analysis, LLM
