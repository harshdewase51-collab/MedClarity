# Sample Medical Reports for Testing & Demo

This directory contains purely synthetic laboratory test reports used for automated testing, API benchmarking, and demonstration purposes.

> [!NOTE]
> All names, dates, values, and clinical contexts in this directory are 100% synthetic and do not contain any private or real personal medical information.

## Included Samples:
1. sample_cbc_panel.txt: Complete Blood Count & Basic Metabolic panel (Hemoglobin, Glucose, WBC, Platelets, ALT, Creatinine).
2. sample_lipid_panel.txt: Comprehensive Lipid & Cardiovascular profile (Total Cholesterol, HDL, LDL, Triglycerides).
